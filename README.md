# 👾 Ultraman – Space Invaders Inspired Game

**Ultraman** is a 2D arcade-style shooter game inspired by the classic *Space Invaders*. Built to practice and apply key **game development** principles and design patterns like **OOP**, **MVC**, and **Service Locator**.

---

## 🚀 Features

- 🎮 Game loop with real-time input and control
- 👨‍🚀 Player and enemy creation with unique behaviors
- 🔫 Shooting mechanics and collision detection
- 🧠 Scoring system based on enemy elimination
- 🔁 Game state transitions (start, play, game over)
- 🎨 Sprite rendering and basic animations
- 🔊 Audio effects and background music
